getStats()

Returns the Beanstalkd stats-tube fields for the queue’s tube as an associative array, with numeric values cast to int (the name field is kept as a string). When the tube exists the result is the full Beanstalkd stats-tube field set (current-jobs-*, total-jobs, the cmd-* counters and tube-configuration fields).

The current-jobs-* backlog keys are always present: an unknown tube (no jobs, not used or watched) has zero backlog, so those keys are returned at zero. This keeps the backlog shape independent of transient watcher state. Runs on a fresh short-lived connection (like purgeQueue) so the read never shares the producer’s socket.
